# rDeboerDesigns

Skills: `ryans-taste` (design, code, copy and voice), `mentor` (advisory board), `mentor-design` (board-directed design on canvas).

## Update flow
Edit the skills in `skills/`, bump `version` in `.claude-plugin/plugin.json`, commit and push. Other accounts refresh with a plugin update.

## Install
Add this repo as a marketplace, then install `rDeboerDesigns` from it.
